# Technical Catalog Contracts

**Physical / technology** asset-type contracts aligned to Collibra Data Catalog + Dataplex Entries, with cross-tool coverage for OpenMetadata, Purview, Alation, and Informatica CDGC.

Catalog SoR = Collibra / Dataplex (and peers). Control Plane consumes stable asset ids for Mapping Engine **DA-09 `represents`**.

## Canonical hierarchies

### Relational

```text
System ──groups──▶ Database ──has──▶ Schema ──contains──▶ Table ──contains──▶ Column
                                              ├─contains──▶ Database View ──contains──▶ Column
                                              └─contains──▶ Stored Procedure
Foreign Key ──composed of / references──▶ Column
```

### File / object storage

```text
File Storage ──contains──▶ Directory ──contains──▶ File ──contains──▶ Field
```

### Streaming / API / process / dataset

```text
System ──contains──▶ Topic | API Endpoint | Dataset | Pipeline
Dataset ──realized as──▶ Table | File | Topic
Pipeline / Stored Procedure ──reads/writes──▶ Table | File | Topic
```
