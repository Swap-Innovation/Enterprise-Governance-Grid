# Data Products Documentation Standard

Every asset type in **`contracts/Data Products/`** uses the same package layout as Technical Catalog.

## Per-asset package

```text
{AssetType}/
  00. README.md
  01. Characteristics.md
  contract.json
  example.json              # Canonical instance (KG / docs SoR)
  examples/                 # Optional extra instances
    {slug}.json
```

Pack-level `examples/index.json` is refs-only.

**Cross-pack / pitch scenarios** live only under [`../examples/`](../examples/) (master).

## Characteristics table columns

Name · Public ID · Description · Kind · Asset Type Filter · Min · Max · System Managed · Read Only · Scope

Scope: `core` · `optional` · `regional` · `legacy`
