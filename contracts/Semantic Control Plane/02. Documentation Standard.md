# Semantic Control Plane Documentation Standard

Same package layout as other `contracts/` packs. These types are **Control Plane SoR objects**, not Collibra catalog assets.

```text
{Type}/
  00. README.md
  01. Characteristics.md
  contract.json
  example.json              # Canonical instance (KG / docs SoR)
  examples/                 # Optional extras (e.g. Namespace NATCOs)
    {slug}.json
```

Pack-level `examples/index.json` is refs-only. Cross-pack scenarios live under [`../examples/scenarios/`](../examples/scenarios/) (master).

Do not confuse with Collibra Guided Stewardship “semantic layer” (Data Model / Entity / Attribute) in Business Catalog.
