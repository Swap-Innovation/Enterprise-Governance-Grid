# Semantic Control Plane Contracts

**Enterprise meaning SoR** — namespaces, concepts, ontology packages, value sets, concept relations, mapping records, federation edges, and semantic policies.

This pack is **not** Collibra inventory. Collibra’s Guided Stewardship “semantic layer” (Data Model / Entity / Attribute) lives in [Business Catalog](../Business%20Catalog/).

**POC SoR lock (SQ2):** Git-backed files in this pack are the system of record. Neo4j is a query materialisation. Peer semantic engines (dbt SL, Databricks Metric Views) are **not** meaning SoR. Metric **calculations** stay beside the layer ([SQ1](../../../docs/strategic-questions/SQ01-semantic-layer-definition.md)).

## How catalogs connect here

```text
Business Catalog  ──mapsTo (DA-08)──────┐
Technical Catalog ──represents (DA-09)──┼──▶ Mapping Record ──targets──▶ Concept
Data Products     ──implements (DA-10)──┘         │
                                                  │ belongs to
                                                  ▼
                                              Namespace
Ontology Package ──contains──▶ Concept
Value Set ──constrains──▶ Concept
Concept ──Concept Relation──▶ Concept
NATCO Concept ──Federation Edge──▶ global Concept
Semantic Policy ──applies to──▶ Namespace / Concept
```
