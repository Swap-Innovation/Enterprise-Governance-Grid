# Business Catalog Contracts

Asset-type contracts for **business / stewardship catalogs**, aligned to Collibra Business Glossary + Guided Stewardship + Report Catalog, with cross-tool coverage for Dataplex, OpenMetadata, Purview, Alation, and Informatica CDGC.

| Layer | Role | Asset types |
| --- | --- | --- |
| **Glossary** | Local business wording (catalog SoR for prose) | Business Term · Acronym · Glossary Category · Measure · KPI |
| **Conceptual (canonical)** | Context-independent business groupings | Data Domain · Data Concept |
| **Semantic (logical)** | Bridge to physical catalog | Data Model · Data Entity · Data Attribute |
| **Context** | Process, governance, issues, reports | Business Process · Business Rule · Policy · Issue · Report · Report Attribute |

Control Plane Mapping Engine binds catalog assets via **DA-08 `mapsTo`** → Registry concepts (`global/*`, `natco-*/*`). Catalog remains SoR for prose; Registry remains SoR for enterprise meaning.

> **Naming note:** Collibra Guided Stewardship calls Data Model / Entity / Attribute the “semantic (logical) layer.” That is **this pack**. The enterprise Semantic Control Plane (canonical concepts) is a **separate** pack: [Semantic Control Plane](../Semantic%20Control%20Plane/).

## Hierarchies

```text
Glossary:     Glossary Category ──contains──▶ Business Term ──has──▶ Acronym
              Measure ──specialized by──▶ KPI ──measures──▶ Business Term

Conceptual:   Data Domain ──contains──▶ Data Concept

Semantic:     Data Model ──contains──▶ Data Entity ──contains──▶ Data Attribute

Context:      Report ──contains──▶ Report Attribute
              Process / Rule / Policy / Issue ──apply to──▶ glossary & semantic assets

Bridges:      Data Concept ──classifies──▶ Data Attribute
              Data Entity ──implemented in──▶ Table
              Data Attribute ──implemented in──▶ Column
              * ──mapsTo──▶ Registry Concept   (Control Plane)
```

## SoR boundary

| Artifact | SoR |
| --- | --- |
| Term / KPI / Measure prose | Collibra (or peer glossary) |
| Conceptual / semantic model assets | Collibra Guided Stewardship (or peer) |
| Canonical enterprise meaning | Semantic Control Plane Registry |
| Crosswalk `mapsTo` | Mapping Engine |
| KPI calculation logic | Beside semantic layer / BI (SQ1) — catalog holds descriptive Calculation Rule only |
