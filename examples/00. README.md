# Examples (docs / pitch)

Pitch and demo JSON used by documentation and (mirrored) by the Vite app under `enterprise-governance-grid/src/data/`.

| Concern | Location |
| --- | --- |
| **Contract type instances (KG enrich)** | `connected-data/10. Contracts/{Pack}/{AssetType}/example.json` |
| Extra instances of one type | `{AssetType}/examples/*.json` |
| Pack example index (refs only) | `{Pack}/examples/index.json` |
| Cross-pack Customer 360 walkthrough | `connected-data/10. Contracts/examples/end-to-end-customer-flow.json` |
| Pitch concepts / TM Forum / graphs | files in this folder |

Do not add new catalog asset instances here — put them under the matching Contracts pack type folder.
