# Customer Domain Context Graph

Traversable **knowledge / context graph** for Customer 360 across **Global + DE / AT / HR / HU / PL** — every NATCO asset set connected to TM Forum SID `Customer`.

## Per NATCO (×5) you see

| Asset | Example (DE) | Connected to global via |
| --- | --- | --- |
| Namespace | `natco-de` | `alignsTo` → `global` |
| Local concept | `kunde` | `sameAs` → `Customer` |
| Local id concept | `kundennummer` | `sameAs` → `CustomerIdentification` |
| Glossary | Kunde | `mapsTo` → `Customer` |
| Table + column | `crm_de.public.kunde` | `represents` → local **and** global |
| Product consume | Customer 360 | `consumes` → NATCO table |
