# Frontend

Vite + React showcase and demo tenant. Live mode proxies `/api/kg` to [`../backend/api/`](../backend/api/).

```bash
npm install
npm run dev        # live (needs Neo4j + kg-api)
npm run dev:mock   # snapshots only
```

See also [`README.md`](README.md).
